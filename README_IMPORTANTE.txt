IMPORTANTE
Esta entrega es una base estática lista para GitHub Pages.
GitHub Pages por sí solo NO permite de forma segura:
- subir archivos desde el navegador y compartirlos a todos los usuarios,
- hacer push al repositorio automáticamente sin credenciales,
- proteger de verdad una página sólo con contraseña front-end.

Para publicación:
1) Sube todo el contenido de esta carpeta a la raíz del repositorio.
2) Asegúrate de que index.html quede en la raíz.
3) Activa GitHub Pages en Settings > Pages.
