# Freskis + La Gran Pantalla

Sitio estático listo para GitHub Pages con:
- index.html: menú, filtros, carrito y envío por WhatsApp
- promociones.html: flyers activos
- videojuegos.html: juegos HTML/Scratch/TurboWarp
- admin.html: panel con contraseña y publicación a GitHub vía API

## Cómo publicar
1. Sube todo el contenido de esta carpeta al repositorio.
2. Activa GitHub Pages desde la rama principal.
3. Abre `admin.html` y usa tu contraseña.
4. Para publicar cambios globales desde el panel, captura owner/repo/branch y un token de GitHub con permisos de contents.

## Importante
Sin backend, la autenticación del panel es de interfaz y la publicación global depende del token de GitHub que capture el administrador en ese momento.
