Panel administrativo

Sesión local cerrada al salir

Esta versión es estática para GitHub Pages. Sirve como base visual y de navegación, pero no puede hacer push directo a GitHub ni actualizar archivos para todos los usuarios sin un backend o un flujo seguro con API/autenticación. En GitHub Pages, cualquier “contraseña” puesta sólo en el front-end puede verse por un usuario técnico.

Qué sí incluye

  • Acceso visual con contraseña de sesión.
  • Navegación separada para administración, promociones y videojuegos.
  • Base lista para personalizar y publicar.
  • Datos del menú cargados desde data/lgp-menu.json y data/freskis-menu.json.

Qué requeriría backend

  • Subir Excel, PDF, PNG o MP3 y que impacte a todos los usuarios en línea.
  • Push automático al repositorio GitHub.
  • Autenticación realmente privada.
  • Persistencia multiusuario segura.

Siguiente paso recomendado

Si quieres, sobre esta misma base se puede hacer una versión 2 con backend usando por ejemplo Supabase, Firebase o una API propia para que el panel admin sí suba cambios, gestione promociones y comparta actualizaciones a todos los usuarios.
